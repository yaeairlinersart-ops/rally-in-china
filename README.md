# 拉力在中国 · RALLY IN CHINA

黑色简约风格的拉力赛事网站筹备页。包含品牌徽标、赛事摄影和“正在筹备”弹窗。

## 本地预览

直接使用浏览器打开 dist/index.html；或安装 Node.js 后执行：

```sh
node server.cjs
```

访问 http://127.0.0.1:4178。

## 部署

静态发布目录为 dist，无构建命令、无第三方运行依赖。自定义域名计划为 rallyinchina.top，尚未在此仓库配置域名或托管。

## 素材

徽标由项目设计生成。摄影沿用本地项目素材，公开使用前需确认使用权。本仓库未授予素材或代码的开源许可。
